
请你帮我开发一款修仙主题的点击类游戏。

# 项目概述
- **技术栈**：纯 HTML + CSS + JavaScript（无需后端，零依赖或仅使用轻量级库）。
- **部署环境**：静态网站（GitHub Pages）。
- **数据存储**：使用 `localStorage` 实现自动存档与离线收益计算。
- **美术风格**：极简水墨风/暗黑文字风（文字为主，使用优雅的排版、CSS渐变和简单的动画）。

# 核心游戏系统与玩法设计
游戏需要具备极高的可玩性和让人上瘾的“数值膨胀”体验，请实现以下系统：

## 1. 基础点击与资源系统（点点点元素）
- **核心资源**：【灵气】。
- **手动获取**：屏幕中央有一个巨大的“修炼”按钮，点击一次获取一定数量的灵气。点击时要有漂浮文字反馈（如 "+1 灵气"），且带有微小的暴击概率（获得双倍灵气）。同时要为修炼添加间隔，防止连点作弊。
- **大数显示**：游戏后期数值会极大，所有资源显示需支持大数格式化（如 1K, 1M, 1B, 1T, 1aa, 1ab 或中文的 万、亿、兆、京）。

## 2. 自动化与养成系统（放置挂机元素）
- 消耗【灵气】可以购买和升级自动化产出项目，增加“每秒灵气产出（QPS）”。
- **养成维度**：
  - 【灵根资质】：增加每次点击获取的灵气量与修炼间隔。
  - 【修仙功法】：基础每秒产出灵气（自动产出）。
  - 【阵法】：按百分比放大全局灵气获取。
  - 【法宝】：解锁特殊机制（如每10秒自动点击一次、降低突破难度等）。
  - 【丹药】：通过服用丹药暂时增加灵气获取量

## 3. 核心大目标：境界突破系统（修仙模拟元素）
- **境界划分**：练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。每个境界分前期、中期、后期、大圆满。
- **突破机制**：当【灵气】达到当前境界上限时，可点击“突破”按钮。
  - 前期境界突破概率为100%。
  - 金丹期及以后，突破有“成功率”（受法宝、丹药加成），一旦失败会扣除部分灵气并进入虚弱期。
  - 突破成功后，获得强大的全局倍率加成，并解锁更高级的功法。

## 4. 轮回转生系统（Prestige / 转生机制）
- **寿元限制**：玩家有【寿命】设定（随现实时间或游戏内Tick流逝），境界越高寿命越长。
- **兵解/羽化（转生）**：当寿命耗尽，或玩家主动选择“兵解重修”时，当前进度重置。
- **转生奖励**：根据本世代达到的境界和累计总灵气，结算发放转生货币【天道结晶】。
- **天道天赋树**：使用【天道结晶】点亮永久天赋（如：初始自带极品灵根、突破成功率永久+20%、暴击伤害+500%等），以此鼓励玩家多次转生。

## 5. 随机奇遇系统（Roguelite 元素）
- 游戏每隔一段随机时间（如3-10分钟），会在屏幕随机位置飘过一个“机缘”。
- 玩家点击后弹出奇遇事件（如：误入前辈洞府、遭遇魔修劫道、捡到神秘残破戒指）。
- 提供2个选项供玩家选择，结果带有随机性（可能获得大量灵气、获得永久Buff，也可能走火入魔扣除灵气）。
